LiDiSoft Design System

The building blocks of the LiDiSoft UI

One CSS file, one JS file and an icon sprite, generated from TOML tokens and component sources by a Go toolchain. No npm anywhere in the pipeline.

How it fits together

tokens/*.toml

Core primitives and semantic aliases. Themes override the semantic layer only.

components/<name>/

Metadata, shadow template, scoped styles and optional behaviour.

dist/lds.css

Fonts, reset, custom properties, theme blocks and layout utilities.

dist/lds.js

The runtime plus every custom element, styles adopted per shadow root.

dist/icons.svg

Build-time Lucide symbol sprite. Injected once for <lds-icon>.

Consuming it

<link rel="stylesheet" href="/lds/lds.css">
<script src="/lds/lds.js" defer></script>

<lds-button variant="primary">Acknowledge</lds-button>

Go services mount the bundle straight from the embedded filesystem — see docs/consuming.md.
